# Generated boundary data

Generated by `scripts/update_boundaries.py` and `.github/workflows/update-boundaries.yml`.

- `countries.geojson`: ADM0 country polygons.
- `countries.json`: ADM0 feature collection and country index.
- `province.json`: global ADM1 polygons, kept under the existing app-compatible filename.
- `district.json`: global ADM2 polygons.
- `boundary-manifest.json`: provenance, download URL, year represented and license fields per source boundary.
- `boundary-update-report.json`: data quality and run summary.

The first successful full workflow run creates these datasets. Do not hand-edit generated JSON. ADM1 and ADM2 labels do not mean exactly the same thing in every country. Read per-source license/attribution fields before redistributing data.
