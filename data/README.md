# Generated boundary data

These files are generated by `scripts/update_boundaries.py` and `.github/workflows/update-boundaries.yml`.

- `countries.geojson`: ADM0 country polygons.
- `countries.json`: lightweight country index and available ADM levels.
- `province.json`: ADM1 index mapping ISO-3 country codes to data files; this is not a combined FeatureCollection.
- `provinces/ISO3.geojson`: simplified ADM1 polygons for one country per file.
- `district-index.json`: index mapping ISO-3 country codes to ADM2 files.
- `districts/ISO3.geojson`: simplified ADM2 polygons, one country per file.
- `boundary-manifest.json`: provenance, geometry URLs, represented years and license metadata.
- `boundary-update-report.json`: coverage, errors and output validation summary.

Generated data appears after the first successful full workflow. Avoid hand-editing generated JSON; edit the source or pipeline instead. ADM levels vary in meaning by country. Review per-dataset license and attribution details before reuse.
